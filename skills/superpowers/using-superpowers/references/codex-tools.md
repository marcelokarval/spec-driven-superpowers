Load `spec-driven-superpowers` through the session's discovered skill path, then
read its `references/adapters/codex.md` and capability protocol. That is the
ASDS mapping; this file preserves the upstream reference entry point.

Do not assume a `Skill` tool, named-agent registry, model, multi-agent feature
flag or app finishing UI. Inspect current tools and CLI help. Do not change
configuration to enable delegation without authorization. Missing delegation
means sequential work, not a failed engineering method.

When workers are available, send the contract plus relevant rules, specs and
approved base. Named reviewer prompts are instructions, not special authority.

unless explicitly authorized, including from detached/sandbox worktrees.
