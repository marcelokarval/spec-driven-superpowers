# Qualification design

Use installed Codex/Agy versions and existing account configuration. Prompts do not name Accelerate/ASDS skills. Three cases per harness: ordinary arithmetic; read-only engineering with missing OpenSpec root; two approved investigations in an existing canonical TASKS.md with an explicit OpenSpec refusal. Read-only or workspace-write is selected per case; Agy headless admission can need a process-local permissions flag. Preserve initial denied attempts rather than silently replacing them.

Record CLI version/path, prompt, session identity, permission mode, public tool-call metadata when exposed, final response, actual file effects and independent root checks. Exclude private reasoning and credential content. A CLI SUCCESS or zero exit is insufficient when response is empty or denied actions occurred. Do not infer subscription billing from model labels; preserve the existing authenticated tools.

A correct conversational outcome proves only the observed scope. Core scheduler/journal use requires a concrete invocation trace; no automatic causal attribution or universal activation claim. A plan-only fixture with no authorization for journals cannot be required to create a journal. Qualify status/resumption by exact returned session id, without changing the objective or overriding skills. Missing independent review remains explicit.

Freeze source and baseline; source-artifact receipts from completed changes remain historical. Local release preparation is reversible; no push, public tag/release or artifact upload follows implicitly. Release version and notes must reflect only what evidence supports.
