# Contributing to ASDS

We welcome contributions to the Autonomous Spec-Driven Superpowers standard, schemas, and skills!

## Principles
1. **Spec-Driven**: Propose changes with OpenSpec delta specifications.
2. **Test-Driven**: Every skill, script, or template must include automated verification tests.
3. **Master-Detail**: Follow the `tasks.md` + `tasks/task-*.md` pattern for multi-step tasks.
4. **Clean Commits**: Atomic, conventional commits per task.

## Development Setup
```bash
git clone https://github.com/Jaoguatirica/spec-driven-superpowers.git
cd spec-driven-superpowers
npm test
```
