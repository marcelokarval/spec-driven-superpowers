# Adaptive task decomposition

## Why
Broad assignments can accumulate implementation and review indefinitely. The owner approved automatic refinement into bounded tasks, even when task counts increase.

## What Changes
- Distinguish one-level packages from executable leaves in the existing canonical plan.
- Review granularity before dispatch; preserve scope, evidence and independent acceptance during refinement.
- Require integrated package proof after child completion.

## Capabilities
### New Capabilities
- task-decomposition: adaptive planning and package acceptance.

## Impact
ASDS contracts, orchestration, source validation, CLI, templates and skill guidance. No tracker, runtime installation, CRM modification or mandatory OpenSpec initialization.
