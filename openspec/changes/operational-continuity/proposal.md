# Operational continuity and source fidelity

## Why
Observed sessions stopped after foundation work, treated a missing validator as a broad blocker, or lost approved visual criteria. The initial portable core required every future task to be ready and had no executable legacy-plan intake or host bridge.

## What Changes
Add opt-in partial plans, operation blockers, pause/resume and next-action decisions; bounded runtime preflight; source-bound projection of existing plans; an injectable host dispatch boundary; approval evidence at acceptance. Preserve Accelerate v1 and existing strict library callers. Update installed skill guidance through the existing owned-file updater.

## Impact
Changes are local toolkit and skills only. Observed projects stay untouched. No installation of external CLIs, trackers or dashboards. Phase 2 remains optional. Automated tests and controlled host probes are distinct from natural-entry Codex/Agy qualification and publication.
