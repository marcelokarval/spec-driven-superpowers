# Natural-entry harness qualification and release preparation

## Why
Portable coordination and operational continuity passed deterministic checks and local review, but natural entry in installed Codex/Agy sessions and versioned delivery remained unproven.

## What Changes
Exercise existing authenticated CLIs against temporary test fixtures with ordinary prompts; preserve public events, failure attempts and effects; assess activation, authorization, existing-plan continuity and actual core use separately. Prepare a local version candidate and release description from the resulting evidence.

## Impact
No alternate installation, auth changes, external project/tracker edits or dashboard rollout. Fixtures are test data, removed after bounded runs and evidence extraction. Publishing externally remains separate from preparing the reviewed candidate.
