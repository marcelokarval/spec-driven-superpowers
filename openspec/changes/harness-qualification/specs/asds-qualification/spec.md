## ADDED Requirements

### Requirement: Honest harness qualification
The toolkit SHALL preserve evidence boundaries when qualifying real installed harnesses.

#### Scenario: Natural entry
- **WHEN** a new harness session receives an ordinary prompt or approved existing work
- **THEN** selection, execution permission, continuation and file effects are evaluated independently using public observations.

#### Scenario: Failed admission
- **WHEN** headless execution denies tools despite a zero exit or success label
- **THEN** the failed attempt remains visible and is not graded as a passed workflow.

#### Scenario: Versioned candidate
- **WHEN** local implementation and bounded harness outcomes are consolidated
- **THEN** version preparation records passed cases and remaining gates without claiming a published or universally qualified system.
